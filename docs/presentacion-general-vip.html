1. ¿Qué es VIP?

VIP (Validación Inventario de Pozos) es una aplicación web institucional que permite a las operadoras cargar y validar su inventario Excel, generar identidad fiscal (UWI), enviar a la ANH un consolidado trazable y habilitar a los funcionarios ANH un panel territorial y un módulo de analítica comparativa.

Para operadoras

Cuaderno de calidad, hallazgos y envío gobernado.

Para ANH

Inventario consolidado, mapa, KPIs y benchmarking nacional.

Para admin

Usuarios y auditoría (stewardship), no decisión analítica.

2. Justificación

  • Fragmentación del dato: el inventario llega en Excel con calidad heterogénea entre operadoras.
  • Costo de revisión manual: sin reglas automáticas, la validación y el UWI son lentos y poco trazables.
  • Necesidad de lectura nacional: la ANH requiere consolidar, mapear y comparar territorios/operadoras.
  • Base para mesa técnica / OTI: demostrar un piloto seguro de aplicación sobre el cual construir plataforma institucional.

3. Objetivos

General

Disponer de una plataforma web que estandarice, valide, consolide y analice el inventario de pozos reportado a la ANH.

Específicos

  1. Automatizar la ingesta y estandarización del Excel oficial.
  2. Aplicar un motor de calidad (~59 reglas) y generación/validación de UWI fiscalizado.
  3. Versionar el trabajo de la operadora (cuaderno) hasta el envío.
  4. Exponer tableros, matrices y analítica comparativa para la ANH.
  5. Generar reportes Excel/PDF de calidad, panel, pozo y analítica.

4. Alcances

Incluye

  • Web app con autenticación por roles y sesión firmada.
  • Pipeline Excel → ETL → validación → cuaderno → envío.
  • Panel con KPIs, mapa, Sankey, rankings y tabla.
  • Analítica ANH (radar base-100, heatmaps, scatter, PDF).
  • Exportes de calidad y reportes PDF.
  • Documentación de cumplimiento, producción y metodologías.

Fuera de alcance del piloto

  • Integración Active Directory / MFA institucional.
  • Base de datos productiva no efímera (PostgreSQL ANH).
  • Modelos de machine learning en producción.
  • Flujos formales Ley 1581 / CSIRT.
  • Correo real a correspondencia ANH (hoy outbox simulado).

5. Limitaciones (declaración abierta)

LimitaciónImplicación
SQLite en /tmp en VercelDatos del piloto pueden reiniciarse; no es producción oficial
Identidad local (no AD)Puente de piloto; falta IdP institucional
Analítica descriptiva/comparativaNo hay forecasting ni ML desplegado
Rate limit por instanciaNo sustituye WAF/perímetro OTI
Mockups de UI en este documentoIlustran la experiencia; la app real puede variar en datos/layout fino
VIP está listo como piloto demostrable y base de trabajo con OTI; la producción institucional requiere persistencia, identidad y gobierno de plataforma.

03ETL + validación
04Revisión hallazgos
05Envío a ANH
06Consolidación
07Tablero / mapa
08Analítica / reportes
  • Operadora: no puede enviar si existen pozos inválidos.
  • ANH: analiza solo inventario validado enviado (más seed de referencia en piloto).
  • Sistema: versiona cuadernos, audita cambios sensibles y recalcula indicadores con filtros.

9. Mensaje de cierre

VIP concentra en una sola aplicación el ciclo cargar → estandarizar → validar → enviar → monitorear → comparar → reportar. Es la base demostrable del inventario de pozos para conversar con OTI sobre persistencia, identidad institucional y puesta en producción, sin perder la lógica de negocio ya construida.

Documentos complementarios en docs/: cumplimiento ANH-GTIC, guía de producción, metodologías de analítica/IA, modelos matemáticos, automatización de datos e indicadores/tableros.
